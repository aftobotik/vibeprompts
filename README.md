# VibePrompts 🚀

**VibePrompts** — это современная, красивая и интерактивная база качественных промптов (запросов) для нейросетей, созданная с использованием концепции *Vibe Coding*.

Этот проект представляет собой коллекцию из 50 профессиональных промптов для ChatGPT, Claude и других ИИ-ассистентов. Все промпты разбиты по категориям и уровням сложности, что делает поиск нужного запроса быстрым и удобным.

## 🌟 Ключевые особенности
- **Интерактивный UI/UX**: Современный дизайн в стиле Glassmorphism с приятными анимациями при скролле и наведении.
- **Удобная фильтрация**: Мгновенный поиск по названию, тегам и технологиям, а также фильтры по категориям и уровню сложности.
- **Всё под рукой**: Возможность скопировать промпт в буфер обмена в один клик или скачать его в виде `.txt` файла.
- **Адаптивность**: Полная поддержка мобильных устройств.

## 🛠 Технологический стек
- **Фреймворк**: [Next.js 14+](https://nextjs.org/) (App Router)
- **Язык**: [TypeScript](https://www.typescriptlang.org/)
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/)
- **Анимации**: [Framer Motion](https://www.framer.com/motion/)
- **Иконки**: [Lucide React](https://lucide.dev/)
